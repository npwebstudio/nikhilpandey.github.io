# Tally – EMI, BMI, Age Calculator and Web Dev Quiz

One file, no build step: everything lives in `index.html`.

## Features
- Loan EMI calculator (monthly EMI, total interest, total payable)
- BMI calculator with category and scale
- Age calculator (years, months, days, next birthday)
- 8-question web development quiz
- Light and dark mode (remembers your choice)

## Run locally
Double-click `index.html`.

## Upload without GitHub (easiest)
- **Netlify:** go to app.netlify.com/drop and drag the folder in. You get a live link in seconds.
- **GoDaddy hosting:** cPanel > File Manager > `public_html` (or a subfolder such as `tally`) > Upload `index.html`. Open `yourdomain.com/tally`.

## Upload to GitHub
1. Create a new repository named `tally-calculator`.
2. Click **Add file > Upload files**, drop `index.html` and `README.md`, then **Commit changes**.
